# Calendar — прототип

Кликабельный прототип веб-календаря на Gravity UI: виды «Неделя / Месяц / День» (на мобильном — «Месяц / 3 дня / 1 день»), создание, просмотр и редактирование событий.

Демо: https://neformatno-rgb.github.io/calendar-prototype/

Весь прототип — один файл `index.html` без сборки. «Сегодня» в демо — 6 января 2027, 10:20.
